隐私政策

一言小账隐私政策
运营主体：xiao jun（个人）
生效日期：2026-11-10
联系方式：hioxiao@qq.com

1. 适用范围
本政策说明一言小账 iOS 版中语音录入、文字记账、本地账本、文件导出和备份恢复的处理方式。本政策适用于一言小账的本地记账功能，以及我们提供的支持页面和联系支持服务。

2. 你输入的账目信息
应用在本机保存金额、人民币币种、收支类型、分类、记账日期、创建时间、记录标识及你输入或确认的原句备注，用于展示、编辑、删除与汇总账目。记录标识由系统随机生成，用于区分账目，不作为广告标识。当前产品没有开发者运营的账号服务、云账本或跨设备同步。

3. 麦克风与语音识别
仅在你主动开始语音记账并授权后使用麦克风。应用调用 Apple Speech / AVFoundation，识别请求强制要求端侧识别，将语音转成文字；当前代码不保存录音文件。停止、取消或进入后台时结束录音。端侧能力或必要系统资源不可用时，你仍可使用文字记账，应用不会自动切换到云端识别。设备和系统资源的首次获取可能依赖网络，由系统管理。你可以在 iOS 设置的“隐私与安全性”中撤销麦克风或语音识别权限。

4. 保存、导出与备份
账本保存在应用沙盒中。你可编辑或删除单笔记录，删除后当前会话内可以撤销最近一次删除。你主动导出时，应用生成 JSON 文件并打开系统分享界面；你选择的接收应用、文件位置及其服务可能按各自政策保存或同步文件。导出过程中可能生成临时文件，由系统或应用后续清理管理；不要把导出文件发送给不可信的接收方。你主动从备份恢复时，应用通过系统文件选择器读取所选 JSON 文件，在本机校验并展示预览；确认后只合并新记录，相同记录跳过，编号相同但内容不同的记录会阻止恢复，不覆盖或删除当前账目。单文件限 1 MB、10000 笔。
iOS 设备备份、iCloud 设备备份或第三方备份工具是否包含应用数据取决于系统和你的设置，并非应用提供的云账本。删除应用并选择删除其数据通常会移除本机应用沙盒，但“卸载 App”可能保留数据；已有设备备份、已导出副本和收件方持有的副本需另行处理。开发者没有远程替你恢复账本的服务。

5. 第三方组件与设备服务
LayaAir / LayaNative 3.4.2 用于界面和运行时；Apple 系统框架用于语音、本地存储、快捷指令与分享。业务层没有接入广告、第三方统计、第三方 AI API 或开发者云服务。这些组件提供界面绘制、脚本运行、端侧语音及系统文件操作。运行时含通用网络与本地缓存能力；本应用未配置广告、行为统计或云账本服务。运行期间设备可能产生本地技术诊断日志；我们不提供自动接收这些日志的开发者服务器。请勿主动向客服发送包含私人账目的诊断材料。
打开公开支持页或隐私政策网页时，网站托管方 GitHub Pages 可能处理连接信息，例如 IP 地址，用于提供及保护网页服务，具体以 GitHub 隐私声明为准。网页行为与账本端侧处理分别说明；网页托管本身不代表账本上传。

6. 联系支持
你主动通过邮箱联系支持时，邮件服务和收件人会处理你发送的邮箱地址、正文与附件，仅用于沟通和处理问题。请不要发送不必要的账本、录音、身份证件或密码。邮件内容在处理请求所需期间保存；如请求删除，可联系上述邮箱，我们会在适用要求和实际可执行范围内处理。

7. 未成年人、变更与联系
本产品是通用个人记账工具，并非专门面向儿童设计。未成年人请在监护人指导下使用；不要在备注中填写不必要的敏感信息。本政策若因功能或处理方式变化而更新，将在支持页面及应用内提供新版本；需要新授权的处理会另行征求同意。有关本政策及数据处理的问题，请联系 hioxiao@qq.com。
