开始记账
输入“今天午饭花了三十二元”，点“识别账目”，核对金额、日期和分类，再点“确认保存”。支持中文单笔人民币收支及今天、昨天等有限表达；请核对识别结果。

语音怎么用？
点“说一句记账”并允许麦克风和语音识别。说完稍停，会尝试自动结束并生成待确认账目；仍可直接点“识别账目”或“完成录音”手动结束。最后需你点“确认保存”，不会自动写账。环境噪声可能延迟自动结束；长句中间停顿过久可能提前结束，可修改文字或重新录入。不支持后台持续监听或唤醒词。

轻点背面怎么设置？
在应用“我的 → 设置快捷记账”查看步骤。系统“快捷指令”中新建“语音记账”，添加“一言小账 → 语音记一笔”，再到“设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下”选择它。锁屏时按系统提示先解锁；看到录音状态后再说话。有未保存内容时先保存或清空，不会自动覆盖。若连续触发无反应，请稍等片刻再试；不要使用后台常驻录音的预期。

离线语音无法使用？
需设备支持中文端侧识别且具备对应系统资源。检查麦克风与语音权限，必要时先恢复网络完成系统资源准备。不具备端侧能力时请使用文字录入；不会自动切换云端识别。

一直显示识别中？
先更新至最新版本，点“识别账目”使用已有转写。若仍无法结束，复制文字后退出再打开应用，并通过邮件反馈系统版本、设备型号、复现步骤；无需发送你的真实账本。

编辑与删除
在“账本”中点一条记录，选择编辑或删除。删除需要再次确认，可撤销最近一次删除。已经导出或备份的副本不会随本机记录自动删除。

备份与换机
在“我的”中导出 JSON 并保存到你信任的位置。可用“从备份恢复”选择 JSON：先查看新增、重复和冲突数，再确认合并。相同记录跳过，有冲突时停止恢复；支持旧版导出的 JSON 数组。单文件限 1 MB、10000 笔，不支持跨设备自动同步。卸载或更换设备前请了解系统备份和恢复设置。

收费与账户
基础功能免费，无需注册应用账号。含 Plus 自动续订月订阅：符合 Apple 资格者可试用 7 天，之后按购买页面显示的价格续订，中国大陆标准价为 ¥20/月。免费版每天 3 次语音，文字记账及账本查看编辑、基础汇总和导出恢复免费。Plus 提供不限量语音、预算与周月分析。

联系支持
请通过 hioxiao@qq.com 反馈问题。邮件建议包括设备型号、iOS 版本、应用版本和操作步骤；截图请先遮挡私人金额及备注。不要发送 Apple ID 密码、验证码或身份证件。

直接修改账目
生成确认卡片后点“修改”，可改金额、收支方向、分类、日期和备注。修改完成后返回核对，再确认保存。也可直接输入金额，无需语音。

月度查看
账本支持上月/下月、分类汇总和筛选，按日期分组。结余仅为已记录收入减支出，不是银行账户余额。小屏可上下滑动，底部导航固定。


Plus 购买与恢复
在“我的 → 了解 Plus”查看价格和资格，确认 Apple 购买弹窗后开始订阅或试用。换机或重装请使用原 Apple 账户，通过“恢复购买”核验。价格或商品暂不可用时，请联网刷新；仍可免费文字记账。

取消和到期
“Plus → 管理订阅”打开 Apple 管理页，也可在系统 Apple 账户的“订阅”中取消。若不续订，请至少在试用结束前 24 小时取消。实际有效期和试用取消结果以 Apple 为准。到期不删除账目，可继续查看、文字记账及导出。长时间离线超过已知到期时间，联网后刷新会员状态。

预算与周月报
“账本 → 预算管理 / 周月分析”为 Plus 功能。预算达到 80% 和 100% 时可提示；需主动允许系统通知才可发送本地通知，系统不保证展示。报表只分析已记录账目，当前周期与上期同期比较，历史周期与上一完整周期比较；上期支出为零不计算增幅。预算设置保存在本机，不包含在账本 JSON 备份中。
